레인 대시

떨어지는 장애물을 피해 30초를 버티는 짧은 피하기 게임입니다.

상태 대기 중
생존 시간 0.0초 / 30초
최고 기록 0.0초
난이도(낙하 속도) 5

게임 규칙

  • 플레이어는 5개 차선 중 한 곳에 있습니다.
  • 위에서 떨어지는 장애물에 닿지 않고 30초를 버티면 성공입니다.
  • 장애물에 부딪히면 즉시 실패합니다.

조작법

  • ← / → 또는 화면의 ◀ ▶ 버튼 : 차선 이동 (한 번 입력 = 한 칸 이동)
  • Space : 일시정지 / 재개
  • Enter 또는 "시작" 버튼 : 시작 / 다시 시작

난이도 설정

바뀌는 값은 낙하 속도 하나뿐입니다. 라운드 진행 중에는 바꿀 수 없습니다. 5단계가 평균적인 난이도이며, 직접 조절해서 플레이할 수 있습니다.
